# THE SOUTHERN CROSS POST — Tuesday 24 November 2026 in one page

One newspaper front page for a single named day, Tuesday 24 November
2026: 34 stories across 9 regions (Europe, Middle East, Africa,
Americas, Asia, South Asia, Asia-Pacific, Oceania, World), every one
checked against that day. The lead is hard news — COP31 ends with no
deal, the first since 2000 — over a number strip, a region count bar, a
dotted world map whose pins match the story numbers, a UTC timeline,
13 full scene cards and briefs 14–34, plus a DATE CHECK box naming the
earlier stories this page deliberately leaves out.

`main.py` (standard library only) carries the finished page: it reads
`entry.png`, verifies the gate (exactly 1024x1024, at most 1 MiB) and
writes the identical bytes to the output directory, so running it any
number of times reproduces the entry byte for byte.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Sources: Reuters, AP, CNN, The Times, Guardian, Treasury, CoinPaprika,
HK News TV, IANS, ObserverVoice, Gadgets360, Mint, NSW, SalonVision.
REPORTED means confirmed by the named source; figures as first reported
Mon 23 – Tue 24 Nov 2026. Pictures and map: original, drawn in code.
